Sales channels

Integrations

Connect Shopify, WooCommerce or a supplier API. Credentials are encrypted at rest and are never returned to this page after saving.

How it works. Test a channel before using it. Import pulls the channel catalogue and links products so stock stays in step; export pushes VELUNE products. Stock sync sends the current price and stock, and sending an order creates the matching remote order once. Every attempt is appended to the activity log.
